# BusinessOS AI Domain Model

## Overview

BusinessOS AI is organized into multiple business domains.

Each domain represents a logical part of the platform and contains its own entities, responsibilities, and business rules.

---

# Core Domains

## Identity

Responsible for authentication, authorization and user management.

Main Entities

- User
- Role
- Permission
- Session

---

## Business

Responsible for business configuration and organizational structure.

Main Entities

- Business
- Branch
- Employee
- Service
- Product
- Working Hours

---

## Customer

Responsible for customer relationships and appointments.

Main Entities

- Customer
- Appointment
- Note
- Tag

---

## Communication

Responsible for omnichannel communication.

Main Entities

- Conversation
- Message
- Channel
- Attachment

---

## Business Knowledge Hub

Responsible for managing business knowledge used by AI.

Main Entities

- Knowledge Source
- Document
- FAQ
- Business Rule
- AI Instruction
- Embedding

---

## AI

Responsible for intelligent automation.

Main Entities

- AI Agent
- Agent Task
- Workflow
- Prompt
- Memory

---

## Operations

Responsible for operational activities.

Main Entities

- Campaign
- Reminder
- Notification
- Calendar Event

---

## Analytics

Responsible for reports and insights.

Main Entities

- Dashboard
- Report
- Metric
- Insight
